MedSimplify is a browser-based AI tool that helps patients understand their medical reports in plain, everyday language. Upload any blood test, MRI, ECG, or discharge summary and get an instant breakdown — no medical background required.
What It Does

Analyzes uploaded medical reports (PDF, PNG, JPG) using AI and explains every parameter in simple terms, flagging values as HIGH, LOW, or NORMAL
Provides personalized food recommendations, lifestyle habits, and things to discuss with your doctor based on your results
Supports output in English, Hindi, and Telugu
Auto-detects the report type or lets you select it manually
Exports the full analysis as a downloadable PDF

Tech Stack

Vanilla HTML, CSS, JavaScript — no frameworks, no backend
Claude AI API for report analysis and language generation
jsPDF for client-side PDF export

Getting Started

Clone the repository
Open index.html in your browser — no build step or server required
Upload a medical report, select your language and report type, and click Analyze My Report
